# بازبینی امنیتی فاز اول فرصت‌ها و مناقصات PDP One

## دامنه

این بازبینی مربوط به Branch `feature/procurement-opportunities-phase-1` و Pull Request پیش‌نویس شماره ۶ است. این سند مجوز Merge یا Deploy نیست.

## وضعیت محیط واقعی

- Production تغییر نکرده است.
- Migration روی PostgreSQL ویندوز اجرا نشده است.
- Volumeهای Docker، فایل‌های خصوصی، `.env`، MCP Token و هویت Tailscale تغییر نکرده‌اند.
- استخراج خودکار در تنظیمات اولیه غیرفعال است.
- Connectorهای ستاد ایران غیرفعال و در انتظار بررسی فنی هستند.

## کنترل‌های پیاده‌سازی‌شده

### دسترسی منابع اینترنتی

- URL استخراج از Templateهای ثبت‌شده Connector ساخته می‌شود و کاربر URL آزاد وارد نمی‌کند.
- فقط HTTPS پذیرفته می‌شود.
- Host مقصد و Redirectها باید در دامنه ثبت‌شده همان منبع باشند.
- قرارگرفتن Username یا Password داخل URL ممنوع است.
- Timeout، Retry محدود و سقف حجم پاسخ اعمال می‌شود.
- شکست یک Connector سایر Connectorها را متوقف نمی‌کند.

### پردازش محتوای منابع

- HTML منبع به‌عنوان کد در مرورگر PDP One اجرا نمی‌شود.
- داده خام در JSONB نگهداری می‌شود و رابط کاربری فقط فیلدهای استانداردشده را نمایش می‌دهد.
- Hash محتوا برای Revision و جلوگیری از پردازش تکراری استفاده می‌شود.
- صفحه امنیتی و دسترسی محدود به‌عنوان وضعیت فنی ثبت می‌شوند و دور زده نمی‌شوند.

### داده و حذف

- PostgreSQL مرجع اصلی رکوردهای ساختاریافته است.
- رکوردهای منتخب و دارای پرونده از Retention خودکار محافظت می‌شوند.
- APIهای فاز اول عملیات حذف مستقیم فراخوان، پرونده یا تحلیل را در اختیار ChatGPT قرار نمی‌دهند.
- تحلیل ChatGPT فقط `AI Draft` ایجاد می‌کند؛ انتخاب، عدم شرکت، ارسال پیشنهاد و تصمیم نهایی خودکار نیست.

### ChatGPT و MCP

- OpenAI API Key یا سرویس پولی جداگانه استفاده نمی‌شود.
- ابزارهای جدید MCP محدود به خواندن Context/Extraction/Notice و ایجاد یا تکمیل Draft تحلیل هستند.
- ابزار عمومی Shell، PowerShell، CMD، تغییر Token، تغییر دسترسی یا Deploy به گردش تحلیل اضافه نشده است.
- زمینه تحلیل نسخه‌بندی شده است و Task ابتدا Manifest سبک را می‌خواند.
- تحلیل تکراری با ترکیب UUID فراخوان، Hash محتوا و نسخه Snapshot کنترل می‌شود.

### زمان‌بندی

- ساعت و دوره استخراج و تأخیر تحلیل در PDP One مرجع واحد هستند.
- Dispatcher فقط Connectorهای تیک‌خورده و منابع فعال را وارد Run می‌کند.
- اجرای هم‌زمان تکراری برای یک Connector کنترل می‌شود.
- تنظیم خودکار اولیه `enabled=false` است و پیش از Preview فعال نمی‌شود.
- فرمان دستی Task فقط پیام مستقل `PDP` است.

### Audit

رویدادهای زیر در Audit ثبت می‌شوند:

- تغییر وضعیت منبع و Connector
- ایجاد یا تغییر پرونده مناقصه/استعلام
- ایجاد فرصت خارج از سامانه و پیگیری
- تغییر تنظیمات زمان‌بندی
- فعال‌سازی Snapshot تحلیل
- ایجاد درخواست، Batch و Draft تحلیل

## کنترل‌های CI

- Secret scan برای الگوهای شناخته‌شده Token و API Key
- جلوگیری از عملیات مخرب Docker Volume
- Parse اسکریپت‌های PowerShell
- آزمون Windows PowerShell 5.1 و DPAPI
- Frontend lint و build/test
- Python compile
- کنترل هم‌خوانی Model و Migration
- تست صف استقرار امضاشده
- تست‌های Backend حوزه‌های Core و Procurement

## موارد نیازمند آزمون در Preview

موارد زیر هنوز تأیید اجرایی نشده‌اند:

1. دسترسی Scheduled Task واقعی ChatGPT به Connected App اختصاصی PDP One بدون حضور کاربر.
2. مجازبودن ثبت خودکار `NoticeAnalysisDraft` در Workspace بدون توقف برای تأیید تعاملی.
3. اجرای فرمان دستی `PDP` در گفت‌وگوی اختصاصی همان Task.
4. هماهنگی Task با تغییر ساعت استخراج و `analysis_delay_minutes`.
5. اجرای واقعی Connectorها در Preview با محدودیت نرخ و تغییر احتمالی ساختار سایت‌ها.
6. نمایش و عملکرد کامل رابط روی موبایل و مرورگر Windows کاربر.
7. Migration و Restore آزمایشی روی کپی ایزوله پایگاه‌داده فعلی، پیش از هر Deploy.

## گیت نهایی

Merge یا Deploy فقط پس از این مراحل مجاز است:

1. CI سبز روی Commit دقیق Preview.
2. بررسی Artifact Preview و مسیر `/procurement`.
3. آزمون Connected App و Scheduled Task.
4. تأیید صریح کاربر روی Preview.
5. Backup نهایی و Restore ایزوله موفق.
6. Deploy همان Commit قفل‌شده و Health Check چندلایه.
