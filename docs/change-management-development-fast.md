# مدیریت تغییرات PDP One در دوره پیاده‌سازی

## هدف

تا زمانی که سامانه در حالت آزمایشی و پیاده‌سازی اولیه است و داده‌های واردشده ارزش عملیاتی پایینی دارند، تغییرات با حالت `development_fast` انجام می‌شوند. هدف، کاهش توقف‌های ناشی از Approval و Backup تکراری است، بدون حذف کنترل‌های فنی اصلی.

## حالت توسعه سریع

این حالت به‌طور پیش‌فرض فقط وقتی فعال است که `PDP_TRIAL_MODE=true` باشد. همچنین می‌توان آن را صریحاً با `PDP_CHANGE_MANAGEMENT_MODE=development_fast` فعال کرد.

جریان تغییر در این حالت:

1. ایجاد Branch مستقل از `main`؛
2. اعمال تغییر فقط در Branch؛
3. اجرای CI شامل تست‌ها، کنترل Migration، اسکن Secret و منع عملیات مخرب Volume؛
4. استقرار Commit دقیق و غیرقابل‌تغییر؛
5. تهیه Snapshot کد فعلی برای Rollback کد؛
6. اجرای Migration کنترل‌شده؛
7. Health Check محلی، عمومی و اتصال ChatGPT؛
8. Audit کامل استقرار؛
9. Merge به `main` فقط پس از موفقیت استقرار و پذیرش عملیاتی.

در این حالت موارد زیر حذف می‌شوند:

- Approval جداگانه برای هر Commit؛
- Final Backup پایگاه داده قبل از هر استقرار؛
- Restore Verification تکراری Backup.

## ریسک پذیرفته‌شده

در `development_fast` بازگشت کد حفظ می‌شود، اما اگر Migration پایگاه داده انجام شده باشد، Rollback پایگاه داده تضمین نمی‌شود. بنابراین این حالت فقط برای دوره‌ای مجاز است که داده‌ها آزمایشی، قابل بازسازی و کم‌اهمیت باشند.

عملیات زیر همچنان ممنوع‌اند:

- حذف یا Prune کردن Docker Volumeها؛
- تغییر یا افشای Token و Secret؛
- حذف خودکار داده‌ها؛
- نهایی یا منتشر کردن تصمیم‌های AI بدون بازبینی انسانی؛
- ایجاد قرارداد فعال یا مالی نهایی از طریق جریان آزمایشی.

## بازگشت به حالت استاندارد

با پایان پیاده‌سازی، یکی از دو اقدام زیر حالت استاندارد را فعال می‌کند:

- تنظیم `PDP_CHANGE_MANAGEMENT_MODE=standard`؛ یا
- غیرفعال‌کردن Trial Mode با `PDP_TRIAL_MODE=false` در صورتی که متغیر صریح مدیریت تغییرات تعریف نشده باشد.

در حالت استاندارد، جریان کامل زیر دوباره اجباری است:

`Branch → Tests → Security Review → Preview → Explicit Approval → Final Verified Backup → Deploy → Health → Rollback on Failure → Merge`

## معیار پایان دوره توسعه سریع

حالت توسعه سریع باید پیش از ورود داده‌های واقعی و بااهمیت، بهره‌برداری رسمی، ثبت قراردادهای عملیاتی یا اتکای مالی به سامانه متوقف شود.
