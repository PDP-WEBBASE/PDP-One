# اتصال آزمایشی PDP One به ChatGPT Business

## نتیجه

PDP One یک سرور MCP مستقل دارد. ChatGPT مستقیماً ابزارهای این سرور را فراخوانی می‌کند و داده‌ها در PostgreSQL لپ‌تاپ یا سرور شرکت باقی می‌مانند. این مسیر به `OPENAI_API_KEY` یا اعتبار OpenAI Platform نیاز ندارد.

## راه‌اندازی خودکار در Windows

1. Rancher Desktop را باز نگه دارید و صبر کنید موتور Moby آماده شود.
2. `CONNECT-CHATGPT.bat` را با دسترسی Administrator اجرا کنید.
3. اسکریپت سرویس‌ها و پایگاه‌داده را بالا می‌آورد، دادهٔ آزمایشی را در صورت نیاز ایجاد می‌کند و یک لینک HTTPS موقت می‌سازد.
4. نشانی کامل MCP به Clipboard کپی و فایل `PDP-ONE-CHATGPT-CONNECTION.txt` باز می‌شود.
5. در صفحهٔ بازشدهٔ ChatGPT، Developer mode را فعال و یک App جدید با گزینهٔ `No Authentication` ایجاد کنید؛ سپس نشانی کپی‌شده را وارد و ابزارها را Scan/Save کنید.

مرحلهٔ پنجم به‌دلیل ورود و تأیید امنیتی حساب ChatGPT باید توسط مالک Workspace انجام شود و قابل واگذاری به اسکریپت محلی نیست.

## ابزارهای نسخه آزمایشی

- بررسی سلامت PDP One و اتصال PostgreSQL
- جست‌وجوی قراردادها و مطالبات
- خلاصه مدیریتی و مالی از داده‌های ذخیره‌شده
- ثبت پیش‌نویس قرارداد
- ثبت پیش‌نویس مطالبه یا صورت‌وضعیت
- ثبت پیش‌نویس دریافت وجه
- ذخیره پیش‌نویس تحلیل ChatGPT با شناسه منابع

هیچ ابزار MCP برای حذف، تأیید قرارداد، قطعی‌کردن سند مالی یا انتشار تحلیل وجود ندارد.

## امنیت نسخه آزمایشی

- مسیر MCP شامل یک توکن تصادفی بلند است و `/mcp` ساده پاسخ 404 می‌دهد.
- لینک اینترنتی فقط تا زمان اجرای پنجره اتصال فعال است.
- بستن پنجره اتصال، لینک موقت را از دسترس خارج می‌کند.
- داده و رمزهای واقعی در GitHub ذخیره نمی‌شوند.
- این حالت برای آزمایش کنترل‌شده است؛ استقرار دائمی شرکت باید دامنه ثابت، HTTPS، OAuth/SSO، سیاست پشتیبان‌گیری و کنترل شبکه داشته باشد.

## آزمون پس از اتصال

در یک گفت‌وگوی جدید از ChatGPT بخواهید:

```text
وضعیت اتصال PDP One را بررسی کن و سپس قرارداد آزمایشی TEST-1405-001 را پیدا کن.
```

برای آزمون نوشتن:

```text
یک پیش‌نویس قرارداد آزمایشی با کد TEST-CHATGPT-001، عنوان «آزمون اتصال ChatGPT» و کارفرمای «شرکت نمونه» در PDP One ثبت کن.
```

ChatGPT باید قبل از اجرای ابزار نوشتن تأیید شما را دریافت کند و نتیجه با وضعیت پیش‌نویس ذخیره شود.
