# PDP One v1.0.0

اولین Release پایدار MVP سامانه PDP One.

## قابلیت‌های اصلی

- استخراج کنترل‌شده مناقصات و استعلام‌ها از Connectorهای فعال
- تحلیل هوش مصنوعی فقط به‌صورت Draft و نیازمند بازبینی انسانی
- مرکز بازبینی AI با تأیید، رد و بازگشت برای تکمیل
- مدیریت مرحله‌ای فرصت‌ها و پرونده‌های منتخب
- تبدیل صریح پرونده برنده به قرارداد پیش‌نویس
- مدیریت مسئول، همکاران، موعدها و یادداشت‌های پیگیری
- داشبورد مدیریتی مبتنی بر داده واقعی
- استخراج افزایشی و صف تحلیل زمان‌بندی‌شده
- اتصال کنترل‌شده ChatGPT از طریق MCP و صف امضاشده محلی

## کنترل‌های پایداری

- استقرار Commit دقیق با CI، Snapshot کد و Rollback
- Backup نهایی PostgreSQL، فایل‌های خصوصی، Redis و Tailscale state
- Restore Verification در PostgreSQL ایزوله
- Mirror اجباری Backup به `D:\BackUp PDP-0NE-14050429-01`
- ثبت مجدد Startup Taskهای ویندوز
- بازگشت Change Management از `development_fast` به `standard`
- غیرفعال‌شدن Trial Mode
- ممنوعیت حذف Docker Volume در ابزارهای استقرار

## وضعیت داده

Release هیچ تحلیل AI را خودکار منتشر نمی‌کند، هیچ قرارداد فعال خودکار نمی‌سازد و هیچ رکورد مالی را بدون اقدام صریح انسانی ایجاد نمی‌کند.
